Which pre-token protocol is worth farming next?

Every protocol below records no token yet. Each one is priced from the snapshot's own figures — what the market already pays for a token in its line of work — and each carries the concrete steps to farm it, with what they cost and how long they take.

How an implied value is worked out

Implied value = TVL × category ratio × growth × maturity × breadth × prior. The ratio is the median market-cap-to-TVL of the protocols in the same category whose token already trades (the whole snapshot's median when a category has too few); growth is the 7-day TVL change; maturity rewards time served with no token recorded; breadth rewards running on more chains; the prior is how often the category has issued a token at all. All five inputs come from the snapshot — no protocol is named by hand. The value is this entry's own claim, never make.fun's, and it says nothing about whether or when a token is issued.

Read carefully: “records no token” means DefiLlama's record carries no token for the protocol. It is not proof the protocol has none. A token may never be issued, and farming costs real money — gas, deposits, time — for a reward that may never come.
